Bike Share Data Analysis
Project Overview
This project analyzes bikeshare data from three major cities: Chicago, New York City, and Washington, D.C.. The goal is to explore various aspects of the bike-sharing systems in these cities, including the most popular times for bike rides, the most popular stations, and trip durations. The analysis is done through an interactive Python script, allowing users to input their own preferences and view customized results.

Installation
Clone the repository:
git clone https://github.com/RicaldoKilaho/Bike-Share.git

Navigate to the project directory:
cd Bike-Share

Install the required packages:
pip install -r requirements.txt

Usage
Run the main Python script to start the interactive analysis:
python bikeshare.py

Users will be prompted to select a city, filter data by month or day, and then receive a summary of statistics related to the chosen data.

Project Details
The project includes the following key features:

Time Statistics: Analyze the most common times of travel (hour, day, month).
Station Statistics: Identify the most popular stations and routes.
Trip Duration Statistics: Calculate total and average trip durations.
User Statistics: Break down the number of users by type, gender, and birth year (when available).

Data Sources
The data used in this project was provided by Motivate, a bike-share system provider for many cities in the United States. The datasets include information on the start and end times of trips, start and end stations, trip duration, user type, gender, and birth year.

Results
This project provides insights into the behavior of bike-share users across the three cities. The results can be used to understand peak usage times, popular stations, and the demographics of users, which can help in making informed decisions for improving bike-share systems.
